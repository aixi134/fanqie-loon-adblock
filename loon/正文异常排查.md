# 正文打不开 → 排查步骤

## 先确认一件事

**手机上现在装的是哪个版本？**

```bash
ios-deploy --list_bundle_id | grep -i dragon
```

刚才查过，只显示了一个：

```
com.dragon.read
```

这说明手机上现在**只有官方版**，自签版 `com.dragon.read-noad` 已经不在了（被官方版覆盖了）。
那么正文异常就不是自签造成的，大概率是 **Loon** 引起的。

---

## 两种可能，先区分开

### 可能 A：MITM 影响了正文请求

`reading.snssdk.com` 同时承载：

- 广告接口 `/reading/commerceapi/*`、`/reading/reader/banner/*`
- 正文接口 `/reading/reader/full`、`/reading/reader/batch_full`

如果 Loon 对这个域名做 MITM 后，正文请求出现任何一点问题（证书、HTTP/2、gzip、超时），
阅读器就会显示「内容加载失败」或「章节加载异常」。

### 可能 B：广告接口被拦后，SDK 认为「内容不可读」

有些阅读器实现里，广告拉取失败会连带影响章节渲染流程。
这种情况下不是网络错误，而是业务逻辑走到了兜底分支。

**区分方法**：把 Loon 插件整个关掉，正文能不能恢复？
- 能恢复 → Loon 的问题（A 或 B）
- 不能恢复 → 客户端缓存或账号状态的问题，见文末

---

## 排查步骤（按顺序做，每步只看一个变量）

### 第 1 步：关掉 Loon，确认基线

```
Loon → 配置 → 全局 → 关闭「代理」总开关（或直接停用插件）
→ 杀掉番茄进程 → 重新打开 → 进一本书
```

**结果**：

| 现象 | 结论 | 下一步 |
|---|---|---|
| 正文恢复正常 | Loon 导致 | 做第 2 步 |
| 正文还是异常 | 不是 Loon | 跳到文末「客户端侧排查」 |

### 第 2 步：只开 MITM，不挂任何规则

用 [番茄分步验证.plugin](番茄分步验证.plugin)，它的 `[Script]` 段默认全部注释掉，
`[MITM]` 只包含 `ad.zijieapi.com` 和 `ib.snssdk.com`——**不含 `reading.snssdk.com`**。

导入后翻页：

| 现象 | 结论 |
|---|---|
| 正文正常，广告也还在 | ✅ MITM 没问题，纯粹是规则的问题 → 做第 3 步 |
| 正文异常 | ❌ MITM 本身就有问题（证书没信任 / 节点问题）→ 做第 2.1 步 |

#### 2.1 MITM 本身有问题

- 确认「证书信任设置」里 Loon CA 开关是**开**的
- 确认节点没挂（浏览器打开任意 https 网站正常）
- 换个节点试

### 第 3 步：只放开 STEP 1（不碰番茄自己的域名）

用 [番茄分步验证.plugin](番茄分步验证.plugin)，它默认只拦截：

```
ad.zijieapi.com/api/ad/v1/banner 等
ib.snssdk.com/api/ad/
pglstatp.com / pangle.io
```

**完全不碰 `reading.snssdk.com`**。

| 现象 | 结论 |
|---|---|
| 插页广告消失，正文正常 | ✅ 方案可用，继续第 4 步 |
| 正文异常 | ❌ 说明连穿山甲接口都不能拦（可能性 B）→ 见下方 |

### 第 4 步：放开 STEP 2（番茄自己的商业化接口）

把 `番茄分步验证.plugin` 里 STEP 2 那三行的 `#` 去掉，重新加载插件，再翻页。

| 现象 | 结论 |
|---|---|
| 正文正常，章末卡消失 | ✅ 全部可用 |
| 正文异常 | ❌ `reading.snssdk.com` 的 MITM 影响了正文，只能停在 STEP 1 |

---

## 如果是可能性 B（拦广告就影响正文）

这说明 App 把「广告可拉取」和「内容可阅读」绑在了一起。可以先试试**只拦物料 CDN、不拦 API**：

```ini
# 只拦广告图片/视频资源，不拦 JSON 接口
URL-REGEX,^https?://[^/]*fqnovelpic\.com/obj/(tomato|novel-ad|ad)/,REJECT
URL-REGEX,^https?://p\d+-[a-z]*\.pstatp\.com/.*(ad|adx|creative).*,(REJECT)
```

广告接口照常返回，但素材图加载不出来 → 卡片显示为空白块或破图，但不会触发「内容异常」。

---

## 客户端侧排查（如果关掉 Loon 也没恢复）

1. **清缓存**：设置 → 番茄小说 → 清除 App 数据（**会丢本地书和进度，先同步**）
2. **换一本书**：排除单本书的内容问题
3. **检查账号**：退出重登
4. **检查是否为已下架/审核中章节**：二进制里这类错误文案是「本章正在审核中」「该书不存在或已停止合作」

---

## 需要你提供的信息

排查时如果卡住了，把这几个信息给我，我能精确定位：

1. **错误提示的原文**（截图或逐字描述：「内容加载失败」/「章节加载异常」/「网络异常」各不相同）
2. **关掉 Loon 后是否恢复**
3. **Loon 日志里正文请求长什么样**：
   ```
   Loon → 日志 → 找 /reading/reader/full 或 /reading/reader/batch_full
   → 记录状态码、耗时、是否被脚本处理
   ```

有了这三项，就能判断是网络层、业务层还是内容本身的问题。
