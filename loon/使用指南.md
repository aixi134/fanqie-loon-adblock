# Loon 使用指南

面向「第一次用 Loon 装第三方插件」的场景，从上一步开始照做即可。

---

## 前置条件

| 项 | 要求 |
|---|---|
| 手机 | iOS，已装 Loon（App Store 付费版） |
| App | **官方版番茄小说**（App Store）。自签版拿不到正文，不要用 |
| Loon 状态 | 已能正常代理（节点连通、全局模式能上网） |

---

## 第一步：装 Loon 根证书（最关键，漏了后面全白做）

```
Loon → 底部「配置」→ 顶部「证书管理」
→ 点「生成新的 CA 证书」
→ 点「安装证书」→ 会跳到系统「描述文件已下载」
→ 设置 → 通用 → VPN与设备管理 → 安装该描述文件
→ 设置 → 通用 → 关于本机 → 拉到最底 → 证书信任设置
→ 找到「Loon CA」→ 打开开关
```

**验证**：证书管理页里「证书状态」应显示已信任。

> `skip-server-cert-verify = true` 只是跳过**服务端**证书校验，
> 客户端（App）仍然要信任你的 CA。这两件事不同，根证书必须先装。

---

## 第二步：放入脚本文件

`adPlaceholder.js` 需要放到手机上好让 Loon 读取。三种方式，任选其一：

### 方式 A：用 Loon 的脚本管理（推荐）

```
Loon → 配置 → 脚本 → 右上角 +
→ 类型选「本地脚本」
→ 把 adPlaceholder.js 的全部内容粘贴进去
→ 文件名填 adPlaceholder.js，保存
```

### 方式 B：AirDrop / 文件 App 传到手机

把 `adPlaceholder.js` 传到手机的「文件」App，记下路径。
然后把插件里的 `script-path=adPlaceholder.js` 改成完整路径。

### 方式 C：把脚本内联进插件（免传文件）

`番茄占位_内联.plugin` 已经把 JS 编码进 `script-path=data:text/javascript,...`，
直接导入即可，不需要单独放 js 文件。**这个最省事。**

---

## 第三步：导入插件

```
Loon → 配置 → 插件 → 右上角 + → 从文件导入
→ 选择 番茄占位.plugin（或 内联版）
→ 插件列表里会多出「番茄小说 广告改写为占位」，打开开关
```

导入成功后点进插件，应该能看到 `[Rule]`、`[Script]`、`[MITM]` 三段内容。

---

## 第四步：确认 MITM 生效

```
Loon → 配置 → 全局 → MITM 开关 ON
→ 点「主机名」查看，列表里应包含：
   ad.zijieapi.com
   reading.snssdk.com
   ib.snssdk.com
```

插件里的 `%APPEND%` 会自动把这些加进去。

---

## 第五步：打开 App 验证

1. 杀掉番茄小说后台（重要：它缓存很强，不杀进程可能看不到变化）
2. 重新打开 → 进书架 → 点开一本书 → 连续翻 10 页以上 → 翻过章末

### 怎么判断有没有生效

用 Loon 的日志面板看：

```
Loon → 底部「日志」→ 看到 ad.zijieapi.com 的请求
→ 点进去，应该有「脚本”标记 + 响应体已被改写
```

| 现象 | 含义 | 下一步 |
|---|---|---|
| 广告标题变成「广告位已屏蔽」 | ✅ 完全生效 | 就是这样 |
| 广告还在，但日志里没有 ad.zijieapi.com | 广告来自其他域名或缓存 | 见下方「排错」 |
| 插页广告整页消失 | 也算成功（SDK 自己走了空分支） | 无需处理 |
| 页面空白/卡住 | 改到了结构字段 | 见下方「排错」 |

---

## 排错

### 广告没变化，日志里也看不到请求

1. **杀进程重开** —— 番茄会缓存整页 Lynx 模板，旧缓存不会重新请求
2. **检查 MITM 是否真的开了** —— 设置里 MITM 总开关 + 主机名列表双重确认
3. **检查证书信任** —— 回到第一步最后一步
4. **测试 MITM 是否工作**：用 Safari 打开 `https://example.com`，Loon 日志里应该能看到这条请求被记录

### 页面变空白

说明改到了布局用的字段。把 `adPlaceholder.js` 里这三行注释掉：

```js
"desc", "description", "ad_description",
```

改完重新粘贴脚本、重新打开 App。

### 只变了部分广告

不同的广告位字段名不一样。把 Loon 日志里那条响应**导出为 JSON 发我**，
我按实际字段名补进 `TITLE_KEYS` / `SUB_KEYS`。

## 进阶：想直接屏蔽而不是占位

换用 `番茄小说去广告.plugin`（REJECT 版）。两者的安装步骤完全一样，
区别只在 `[Rule]` 段：REJECT 版是直接拒绝请求，占位版是放行后改内容。

| | REJECT 版 | 占位版 |
|---|---|---|
| 广告位是否消失 | 消失 | 保留占位 |
| 会不会出现空白页 | 有可能 | 不会 |
| 适合 | 想要干净页面 | 想先看效果/求稳 |

## 常见疑问

**Q：需要全局模式吗？**
不需要，规则模式下插件规则优先生效。

**Q：会不会影响正文？**
不会。正文走 `/api/novel/book/reader/content/v1` 和 `/reading/reader/full`，
这两个路径**不在任何规则、不在 MITM 主机名列表**里。

**Q：耗电吗？**
MITM 只对两个域名开启，影响很小。

**Q：能拦掉所有广告吗？**
不能。段中内嵌广告的物料随正文一起下发，离线假广告页是纯本地行为，这两个拦不到。
详见 [说明.md](说明.md) 的「已知拦不到的部分」。
